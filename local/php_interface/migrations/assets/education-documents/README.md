# PDF-документы образовательной организации

Исходник — папка «Форсаж для сайта», переданная пользователем 20 октября 2026 года. Манифест `documents.json` содержит 45 документов, их разделы, названия, порядок и исходные имена файлов. PDF сохранены без изменений. Для трёх пар одинаковых исходников используется один файл миграции, всего 42 PDF объёмом около 75 МиБ.

Миграция `Version20261020133715` создаёт элементы в инфоблоке `content:education_documents` и подраздел «Программы» в разделе «Образование». Сначала должна быть установлена миграция `Version20261020111458`. Числовые ID находятся на каждом стенде по символьным кодам.

При повторном запуске миграция сверяет SHA-256 уже прикреплённых файлов и не загружает их заново. Если редактор заменил PDF, миграция останавливается до изменения данных. Существующие названия, сортировка и привязки к разделам сохраняются.

Откат отключает только импортированные документы. Элементы, разделы и прикреплённые PDF сохраняются. Повторный запуск включает эти документы с прежними файлами.

## Совпадения в исходной папке

- «Отчет самообследования ЧОУ ДПО Форсаж 2026.pdf» и «Акт самообследования ЧОУ ДПО Форсаж 2026.pdf» совпадают.
- «Заключение ГИБДД 07.08.2026.pdf» находится в двух основных разделах и совпадает.
- «Финансирование образовательной деятельности.pdf» совпадает со «Сведения о численности.pdf» и содержит сведения о численности обучающихся. Название и содержимое сохранены в соответствии с переданными исходниками. Перед публичным выводом нужно проверить этот файл у владельца документов.
